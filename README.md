# PragyaRoot Experiment

A separate sandbox for exploring the next version of PragyaRoot without changing the production repository.

## Non-negotiable visual rule

PragyaRoot is strictly monochrome:

- Pure black and pure white
- Impure blacks and whites: charcoal, graphite, grey, silver, mist, off-white
- No hue-based brand colors
- No colored gradients
- No decorative color accents

The premium feeling must come from typography, spacing, contrast, composition, texture, motion, and interaction quality.

## Product ambition

Make PragyaRoot feel like a serious, calm, powerful learning product—not an old-fashioned tuition site or generic course app.

Quality targets:

- Premium brand system
- Excellent accessibility
- Strong SEO foundation
- Fast, offline-friendly performance
- Clear, focused UX
- High-quality learning, practice, and revision flows

## Repository boundary

This experiment is intentionally separate from saurav27p/pragyaroot. Do not modify the production repository while exploring here.
